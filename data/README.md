# NightWatch Data Directory

This directory stores raw and processed synthetic data generated by the NightWatch simulation pipeline.

## Directory Structure

- `raw/`: Stores raw synthetic cohort outputs:
  - `patients.parquet`: Demographic and baseline clinical EHR profiles for 200 synthetic patients.
  - `ehr_events.parquet`: Coded longitudinal EHR events (diagnoses, labs, medications, vitals).
  - `sensor_readings.parquet`: High-frequency simulated wearable readings (sleep stages, duration, HRV RMSSD, resting HR, steps, medication timestamps) and home BP cuff measurements (morning and evening SBP/DBP).
- `processed/`: Stores fused and aligned tabular datasets:
  - `features_daily.parquet`: Fully engineered daily feature matrix with personal baseline z-scores and aligned binary target labels (`hypertensive_episode`).

## Clinical Ground Truth & Data Hygiene

1. **Home BP Cuff Readings as Ground Truth**: Wearable devices provide physiologic context (sleep, autonomic tone via HRV, activity). Smartwatches do not measure blood pressure.
2. **Causality & Zero-Leakage**: All feature extractions for day $t$ use only observations strictly prior to time $t$.
3. **Synthetic Guarantee**: All records in this directory are purely synthetic and generated via reproducible pseudo-random distributions for research and decision-support prototype demonstration.
